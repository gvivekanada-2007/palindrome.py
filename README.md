🔄 Palindrome Checker (Python)
A simple Python script that checks whether a given string is a palindrome — a word or phrase that reads the same backward as forward.

🧠 How It Works
The program:

Defines a string s.

Calculates the middle length ml = n * 2.

Compares characters from the start and end of the string.

Prints whether the string is a palindrome or not.

output example:
a a
b b
c c
yes it is a palindrome

🧩 Future Enhancements
Accept user input dynamically.

Ignore spaces, punctuation, and case sensitivity.

Extend to check numeric palindromes.
